## Language

**Archived tournament**:
A tournament its creator has hidden from the dashboard's default lists (`archived: true`); still
reachable by URL and restorable. Not deleted.
_Avoid_: hidden, closed, soft-deleted

**Creator**:
The admin whose user id is a tournament's `createdBy`; the only user who may archive or delete it.
_Avoid_: owner
